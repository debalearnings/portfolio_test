The project

Overview

Touch during virtual interaction has several components: where contact occurs, how a surface changes beneath the fingertip, and how an object resists a grasp. This glove combines these channels through flexible finger sensing, 2×2 pneumatic fingertip arrays, and a motor–tendon mechanism that provides kinesthetic resistance to the thumb, index, and middle fingers.

A ROS-based interface links the physical glove to Unity, where colliders and object properties determine tactile and force-feedback commands. The study evaluates virtual manipulation, spatial and directional sensation, stiffness discrimination, and perceived workload. A later extension used the glove to teleoperate an Allegro hand; its dedicated case study will be added here.

My contributions

  • Developed flexible finger-sensing and multimodal feedback components within the soft-glove research project.
  • Integrated pneumatic cutaneous rendering with motor–tendon kinesthetic feedback for virtual contact and object stiffness.
  • Connected glove signals, wrist tracking, Unity interactions, and feedback control through ROS-based communication.
  • Designed and conducted psychophysical manipulation and discrimination tasks, alongside NASA-TLX workload assessment.
01

Bend sensing and wrist pose

Tracking the hand with compliant sensors

Custom Velostat-based flexible bend sensors measure finger motion, while a wrist-mounted Vive Tracker supplies hand position and orientation. The compliant sensing elements fit along the fingers without requiring a rigid joint linkage, allowing the virtual hand to follow the wearer during grasping and release.

Sensor development includes static and dynamic characterization, neural modeling, and geometry optimization to balance sensitivity, usable angle range, response time, and fit. Mapping resistance to finger configuration then provides the pose information used by the virtual interaction model. This sensing channel is separate from the tactile output arrays mounted at the fingertips.

02

Pneumatic 2×2 tactor arrays

Rendering contact at the fingertip

Each fingertip array contains four individually addressable pneumatic tactors. Local deformation indicates contact position, while sequences of activation convey the direction of movement across a slot or surface feature. Finite-element and experimental characterization connect the elastomeric structure to the pressure needed for perceptible deformation.

This spatial feedback complements a single contact signal: a wearer can receive a sequence that changes as the fingertip crosses a virtual feature. The glove’s 2×2 arrays are a later, distinct design from the standalone 3×3 pneumatic tactile display developed during the Sant’Anna visit.

03

Backdrivable motor–tendon feedback

Making a virtual object resist the grasp

A motor–pulley arrangement transmits force through Bowden tendons to the fingers. Before contact, the system permits finger movement; after virtual contact, it resists further closure according to the object interaction. Independent cascaded position–current control supports this behavior for the thumb, index, and middle fingers.

The controller can vary resistance to represent object stiffness, complementing the pneumatic arrays’ cutaneous indication of contact. The reported system can provide up to 5 N of resistive force per finger. This is a rendered interaction force at the glove, not a direct measurement of force on a physical remote object.

04

Unity · ROS · feedback control

Closing the loop through the virtual environment

Finger sensors and wrist tracking update the hand avatar in Unity. Collider-based contact and virtual object properties then determine which tactors activate and how the tendon-feedback system resists movement. The loop makes the same interaction available through visual motion, local touch, and finger resistance.

The reported implementation uses ROS 1 communication with Unity and the associated LabVIEW/DAQ control components, including sbRIO-based feedback. Demonstrations show virtual grasping and manipulation. Later Allegro-hand teleoperation is recorded in the CV, but remains an extension requiring its own media and technical description before it is presented as part of this demonstrated setup.

05

Psychophysics and interaction workload

Testing what the wearer can perceive and use

Evaluation separates several questions: whether users can manipulate virtual objects, identify spatial or directional tactile information, and distinguish rendered stiffness. Repeated randomized stimuli and discrimination tasks probe the feedback channels, while object-manipulation trials examine their use during an interactive activity.

NASA-TLX adds a workload perspective to task performance, and repeated trials show how interaction changes with practice. These experiments support the glove’s use as a multimodal VR interface within the tested tasks.
